# 📚 Readify – Manual Testing Project

## 📌 Project Overview

Readify is a JavaFX-based Online Book Management System that allows users to register, login, browse books by category, read PDF books, manage a personal library, and interact with a chatbot.

This repository contains complete Manual Testing documentation prepared by following the Software Testing Life Cycle (STLC).

---

## 🎯 Objective

The objective of this project is to perform end-to-end manual testing and ensure all functional requirements are validated with proper documentation and defect reporting.

---

## 🧪 Modules Tested

- Authentication (Login & Registration)
- Dashboard
- Category Management
- Book Listing
- PDF Viewer
- My Library
- Chatbot
- Logout
